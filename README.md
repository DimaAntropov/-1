РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ
Автоматизированная система учёта «RestoBookApp»


1. ОБЩИЕ СВЕДЕНИЯ
1.1. Назначение и область применения
Программное изделие «RestoBookApp» (далее — Система) является автоматизированной системой, предназначенной для учёта и управления информацией о бронированиях столиков в ресторане.
Областью применения Системы является деятельность административного и управляющего персонала заведений общественного питания.
Основные функции Системы:
•	Ведение базы данных клиентов (регистрация, хранение контактных данных).
•	Ведение каталога столиков ресторана (учёт номеров, вместимости, расположения).
•	Управление бронированиями (создание, просмотр, отмена броней).
•	Управление учётными записями пользователей с разграничением прав доступа по ролям («Директор», «Менеджер»).
1.2. Краткое описание возможностей
Система предоставляет следующие функциональные возможности:
•	Авторизация пользователей: Доступ к функциям Системы осуществляется по уникальному имени пользователя и паролю.
•	Ролевая модель доступа: 
o	Пользователи с ролью «Директор» или «Администратор» имеют полный доступ ко всем данным: клиентам, столикам, бронированиям и учётным записям пользователей.
o	Пользователи с ролью «Менеджер» (или иной) имеют доступ только к данным о клиентах и бронированиях.
•	Управление данными: Просмотр, добавление и удаление записей в таблицах.
•	Обновление данных: Принудительное обновление информации, отображаемой в таблицах, из базы данных.
Примечание: Редактирование существующих записей в данной версии не предусмотрено. Для внесения изменений необходимо выполнить удаление некорректной записи с последующим добавлением новой.
1.3. Требования к уровню подготовки пользователя
Пользователь должен обладать следующими навыками:
•	Базовые навыки работы с персональным компьютером под управлением операционной системы семейства Microsoft Windows.
•	Навыки работы с клавиатурой и манипулятором типа «мышь».
•	Понимание предметной области (процессы бронирования, учёт клиентов).
Специализированное обучение для работы с Системой не требуется.
1.4. Перечень эксплуатационной документации
•	Настоящее Руководство пользователя (РБА.2024.001-РП).

2. УСЛОВИЯ ПРИМЕНЕНИЯ
2.1. Требования к техническим средствам
•	Процессор: Intel Core i3 / AMD Ryzen 3 или более производительный.
•	Оперативная память (ОЗУ): не менее 4 ГБ.
•	Свободное место на жёстком диске: не менее 100 МБ.
•	Монитор: с разрешением не менее 1024x768 пикселей.
•	Периферийные устройства: клавиатура, мышь.
2.2. Требования к программному обеспечению
•	Операционная система: Microsoft Windows 7/8/10/11 (x86 или x64).
•	Платформа .NET Framework: версия 4.7.2 или выше.
•	Microsoft Access Database Engine 2010/2016 Redistributable: Обязательный компонент. Разрядность установленного компонента (x86 или x64) должна соответствовать разрядности исполняемого файла Системы.

3. ПОДГОТОВКА К РАБОТЕ
3.1. Состав и размещение программного изделия
Дистрибутив Системы поставляется в виде набора файлов, включающего:
•	RestoBookApp.exe – исполняемый файл.
•	Restaurant.accdb – файл базы данных.
•	RestoBookApp.exe.config – конфигурационный файл.
•	Настоящее руководство.
Важно: для корректной работы Системы файлы RestoBookApp.exe и Restaurant.accdb должны быть размещены в одном каталоге.
3.2. Порядок загрузки Системы
1.	Убедитесь, что на компьютере установлен компонент Microsoft Access Database Engine (см. п. 2.2).
2.	Разместите файлы дистрибутива в одном рабочем каталоге.
3.	Запустите исполняемый файл RestoBookApp.exe.
4.	На экране появится форма «Авторизация».
3.3. Проверка работоспособности
1.	Выполните запуск Системы (см. п. 3.2).
2.	В форме «Авторизация» введите действительные имя пользователя и пароль. Нажмите кнопку «Войти».
3.	При успешной авторизации должно открыться главное окно Системы.
4.	Нажмите кнопку «Обновить». Таблицы на вкладках должны заполниться данными. Сообщения об ошибках должны отсутствовать.
5.	Если указанные действия выполнены успешно, Система готова к эксплуатации.
4. ОПИСАНИЕ ОПЕРАЦИЙ
4.1. Операция «Авторизация пользователя»
•	Назначение: Получение доступа к функциям Системы.
•	Условия: Система запущена, отображается форма «Авторизация».
•	Порядок выполнения: 
1.	В поле «Имя пользователя» введите логин.
2.	В поле «Пароль» введите пароль.
3.	Нажмите кнопку «Войти».
•	Результат: При успешной авторизации открывается главное окно Системы. При вводе неверных данных выводится сообщение об ошибке.
4.2. Операция «Просмотр данных»
•	Назначение: Отображение информации из базы данных.
•	Условия: Пользователь авторизован, главное окно Системы открыто.
•	Порядок выполнения: 
1.	Перейдите на вкладку, соответствующую требуемым данным («Клиенты», «Столики» и т.д.).
2.	Для обновления информации нажмите кнопку «Обновить».
•	Результат: В таблице на активной вкладке отображаются актуальные данные.
4.3. Операция «Добавление записи»
•	Назначение: Внесение новой информации в базу данных.
•	Условия: Пользователь авторизован, открыта вкладка, в которую необходимо добавить запись.
•	Порядок выполнения: 
1.	Нажмите кнопку «Добавить».
2.	Система последовательно выведет диалоговые окна для ввода данных, соответствующих полям таблицы.
3.	Введите запрашиваемые значения в каждое окно и подтвердите ввод.
•	Результат: После ввода всех данных в базу добавляется новая запись. Для её отображения необходимо нажать кнопку «Обновить».
4.4. Операция «Удаление записи»
•	Назначение: Перманентное удаление информации из базы данных.
•	Условия: Пользователь авторизован, в таблице на активной вкладке выбрана одна строка для удаления.
•	Порядок выполнения: 
1.	Щелчком мыши выделите строку, подлежащую удалению.
2.	Нажмите кнопку «Удалить».
3.	В диалоговом окне подтвердите операцию удаления, нажав «Да».
•	Результат: Запись удаляется из базы данных. При попытке удаления записи, имеющей связи в других таблицах (например, удаление клиента с активными бронированиями), Система выведет сообщение об ошибке.

5.Также как зайти под админом ввидите в 1 строке a это логин а во 2 h1 это пароль.
